- `mark.wobble` was read only from the preset's `mark_wobble`, so a deck's `style.tokens.mark_wobble` did nothing in either renderer. Both `render_core.Style.wobble` and `card.js` now read the merged token first and fall back to the preset. The parity check exercises the token path with `mark_wobble` 0 and 2.
- A PDF differed from the same deck rendered again on every run, in the `/CreationDate` and `/ModDate` metadata that Pillow and Chromium stamp from the clock. `render_core.canonical_pdf` now rewrites both dates to a fixed value at the same string length, so the PDFs, PNGs, HTML sheet and fit report are byte-identical on repeat runs. `DECISIONS.md` D-029 records it.
- The first raster print PDF put two 5 in cards across an 8.5 in page, so the second card was clipped. It now stacks them, matching the HTML sheet.
